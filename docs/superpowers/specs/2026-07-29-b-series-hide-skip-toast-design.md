# B 版隐藏跳过工作簿提示设计

## 背景

批量导入遇到重复档案时，用户可以明确选择“跳过”。当前处理完成后，页面顶部会额外显示“已跳过该工作簿”的临时提示；与此同时，当前批次结果和永久导入历史已经通过 `SKIPPED` 状态记录相同结果，因此这条顶部提示属于重复反馈。

## 决策

用户确认跳过工作簿后，不再设置或显示“已跳过该工作簿”的页面级临时提示。

覆盖导入成功后的“已将工作簿设为新的有效档案”提示保持不变，以便继续反馈实际的数据变更。

## 范围

本次只调整 B 版客户端重复决策完成后的临时消息，并补充状态层回归测试。以下行为保持不变：

- “跳过”按钮和 `SKIP` 请求仍然存在；
- 当前批次项目仍显示“已跳过”状态；
- 永久导入历史仍保存并显示跳过结果；
- 后端仍持久化 `SKIPPED` 结果和审计记录；
- 覆盖导入、普通导入、失败反馈及其他提示保持不变。

## 验收与测试

1. 重复档案选择“跳过”并成功返回后，状态层不再产生“已跳过该工作簿”临时消息；
2. 同一项目仍更新为服务端返回的 `SKIPPED` 结果；
3. 选择“覆盖”成功后仍显示原有成功提示；
4. 现有类型检查、单元测试和构建保持通过。
