# B 版重复档案弹窗关闭控件优化设计

## 背景

批量导入发现重复档案时，页面先打开“发现重复档案”外层弹窗；选择覆盖后再打开“确认覆盖档案”二次确认框。Element Plus 默认把关闭按钮放在弹层右上角 `top: 0; right: 0`，与 B 系列弹窗的 3px 钴蓝顶线和圆角边缘重叠。二次确认出现时，屏幕还会同时看到内外两个叉号，关闭层级不明确。

## 方案比较

1. **外层规范定位，二次确认隐藏叉号（采用）**：普通查看阶段保留快捷关闭；进入高风险覆盖确认后只允许用户通过“返回检查”或“确认覆盖”表达决定，层级最清楚。
2. **两个叉号都保留并统一定位**：实现简单，但仍同时展示两个含义相近的退出控件，无法消除关闭层级歧义。
3. **两个叉号都移除**：界面最简，但外层弹窗在普通查看阶段失去符合桌面习惯的快捷取消入口。

## 视觉与交互设计

沿用 B 卷宗检阅桌现有色彩和字体，不新增视觉体系：钴蓝 `var(--dossier-primary)`、浅蓝底 `var(--dossier-primary-wash)`、墨色 `var(--dossier-ink)`、弱边线 `var(--dossier-line-soft)`。

外层“发现重复档案”弹窗：

- 关闭按钮使用 32×32px 点击区域，距标题区上边和右边各 16px；
- 16px 叉号在点击区域内居中，不接触 3px 顶线或圆角；
- 默认使用弱文字色，悬停时显示浅蓝底和钴蓝图标，键盘聚焦保留清晰焦点环；
- 标题区右侧为关闭按钮预留空间，长标题不与控件重叠。

```text
┌─ 钴蓝顶线 ─────────────────────────┐
│ 发现重复档案                 [ × ] │
├───────────────────────────────────┤
│ 档案摘要与覆盖/跳过选择            │
└───────────────────────────────────┘
```

二次“确认覆盖档案”弹窗：

- 不渲染叉号；
- 禁止点击遮罩关闭，避免误把点击空白理解为取消；
- 保留 Esc，将其视为“返回检查”，满足键盘用户的取消习惯；
- 打开二次确认期间，外层叉号同时隐藏且外层 Esc 关闭暂停，避免一次操作影响两层；
- 二次确认结束后，外层叉号和 Esc 关闭能力恢复。

## 实现边界

- `ImportPage.vue` 增加一个仅表示二次确认是否打开的本地状态；该状态不进入 Pinia，也不改变导入业务状态机；
- `ElMessageBox.confirm` 增加 `showClose: false` 和 `closeOnClickModal: false`；
- 外层 `ElDialog` 的 `show-close` 与 `close-on-press-escape` 由二次确认状态控制；
- `dialogs.css` 只调整共享 `ElDialog` 关闭按钮的尺寸、内边距、悬停和聚焦表现；不改变弹窗宽度、正文或按钮区；
- 后端 API、重复判定、默认 `SKIP`、覆盖确认文案、取消/异常处理和审计逻辑保持不变。

## 测试与验收

组件回归测试应证明：

1. 外层重复档案弹窗单独打开时仍有一个关闭按钮；
2. 进入二次覆盖确认后，内层和外层都不显示叉号；
3. 点击“返回检查”后，二次确认关闭、外层弹窗保留且外层关闭按钮恢复；
4. `ElMessageBox` 的其他异常仍继续抛出，不被误判为取消；
5. 单元测试、样式检查、类型检查和生产构建通过。

视觉验收时，在 B 版批量导入页触发重复档案：外层叉号应与标题垂直协调并远离蓝色顶线；二次确认画面中不应再出现截图标记的两个叉号。
