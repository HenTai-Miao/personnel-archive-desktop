# B 系列人员页辅助区域删除设计

**日期：** 2026-07-28  
**实现目录：** `personnel-archive-desktop-b`  
**用户确认：** 只删除截图红框标记的两块；独立档案详情页目录保留。

## 1. 目标

删除登录后左侧业务目录底部的“卷宗已安全载入 / 敏感字段默认遮罩”状态卡，以及人员档案主页右侧的“卷宗目录”。删除后不留下空列、空容器或窄屏替代目录，中间档案阅读区域使用释放出的宽度。

本次只精简展示结构，不改变档案列表、详情读取、敏感字段遮罩、照片、批量导出、删除权限、路由或服务端请求。

## 2. 方案选择

采用真正移除组件的方案：

- 从 `AppShell.vue` 删除侧栏状态卡 DOM，并删除只服务于该卡片的 CSS；
- 从 `PersonListPage.vue` 删除 `DossierOutline` 引用、人员页章节常量和目录实例；
- 把人员阅读桌从“索引 + 档案 + 目录”三列改为“索引 + 档案”两列；
- 在 1320px 及以下继续缩窄人员索引，但不再生成横向章节目录。

未采用的方案：

1. 仅用 CSS 隐藏：会保留无用 DOM、响应式分支和测试契约，后续容易再次出现；
2. 全局删除 `DossierOutline`：会误删用户明确要求保留的独立详情页目录，也会影响文件夹设置页现有能力；
3. 保留人员页窄屏目录：与“删除右侧卷宗目录”语义不一致，且同一组件会在改变窗口宽度后重新出现。

## 3. 页面结构

### 3.1 登录后应用骨架

- 252px 业务目录宽度、导航入口、顶栏“安全会话已建立”和用户区保持不变；
- 仅删除侧栏底部状态卡；由于它属于共享 `AppShell`，删除后所有登录后业务页都不再显示该卡；
- 侧栏底部保持自然空白，不新增替代说明或装饰。

### 3.2 人员档案主页

桌面结构改为：

```text
┌──────────── 286px 在册卷宗 ────────────┬──────────── 完整档案阅读区 ────────────┐
│ 筛选、人员、分页                         │ 初始提示 / 加载 / 失败 / 完整卷宗         │
└─────────────────────────────────────────┴───────────────────────────────────────┘
```

- 1440px 等桌面宽度保持 286px 人员索引，档案区占满剩余宽度；
- 1320px 及以下使用 240px 人员索引和自适应档案区；
- 1080px 最小窗口不产生工作区级横向滚动；
- 空状态、完整卷宗和错误状态都使用相同的两列网格，不因是否选中人员改变宽度。

### 3.3 独立详情页

`ArchiveDetailPage.vue` 和共享 `DossierOutline.vue` 不修改。用户点击“独立查看”后，详情页仍提供桌面右侧章节目录及窄屏横向章节导航。

## 4. 行为与安全边界

- 人员列表仍只在显式选择记录后读取完整详情与鉴权照片；
- 批量勾选与当前卷宗选择继续相互独立；
- 身份证、手机号遮罩及显式查看行为不变；
- 顶栏安全会话状态保留，删除侧栏卡片不代表删除或弱化任何安全机制；
- Electron IPC、路由、权限、分页容量和后端接口均不变。

## 5. 测试与文档

- 应用骨架组件测试明确断言 `.sidebar-security-note` 不存在，同时保留顶栏安全会话断言；
- 人员页组件测试明确断言人员主页不渲染 `.dossier-navigation`、`.dossier-outline` 或 `.dossier-mobile-index`；
- Electron 布局测试在 1440px 验证人员页只有两列（286px + 自适应内容），在 1080px 验证目录的桌面和移动形态均不存在、档案可见且工作区无横向溢出；
- 详情 E2E 把章节跳转验证移到独立详情页，证明详情目录仍然可用；
- 更新本客户端 `AGENTS.md` 与根目录 `CODE_GUIDE.md`，只描述人员主页的两列变化，不宣称 B 副本已经晋升为正式打包源。

## 6. 完成标准

1. 截图两个红框区域均不再渲染；
2. 人员主页释放右侧 238px 空间且没有残留空列；
3. 1080px 下不出现人员页横向章节目录，也没有工作区级横向滚动；
4. 独立详情页目录和章节定位继续正常；
5. 既有业务行为、安全边界、单元测试、构建和 Electron E2E 全部通过。
