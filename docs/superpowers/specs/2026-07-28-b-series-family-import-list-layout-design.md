# B 系列家庭查询与批量导入纵向布局设计

**日期：** 2026-07-28  
**实现目录：** `personnel-archive-desktop-b`  
**基线检查点：** `b-series-v1-before-list-redesign`（提交 `535845a`）

## 1. 目标

将“家庭成员查询”和“批量导入档案”恢复为 `personnel-archive-desktop` 当前版本使用的全宽纵向信息结构，同时保留 `personnel-archive-desktop-b` 的钴蓝/白纸视觉系统、应用骨架、交互状态和全部业务契约。

本次改版只调整这两个页面及其直接样式和测试，不修改后端 API、Electron IPC、路由、权限、自动归档、重复决定、分页容量或敏感数据边界。

## 2. 设计原则

1. 结构以原版为准：搜索、文件选择、当前结果和历史数据从上到下阅读，不使用左右主从面板或三栏批次目录。
2. 视觉以 B 版为准：继续使用 `#034ed6` 主色、白色纸页、细边框、克制阴影、等宽英文眉题和现有按钮/状态样式。
3. 逻辑保持现状：继续复用现有 Pinia store、feature API、固定 20 条分页、重复决定弹窗和本地归档反馈。
4. 状态完整可见：加载、初始空白、无结果、失败、待决定、部分成功和永久历史失败都在原位置给出明确反馈。
5. 适配 1080px 最小窗口：页面保持单列纵向；字段较多的结果表格允许在纸页内部横向滚动，不压缩到不可读。

## 3. 家庭成员查询

### 3.1 页面结构

页面继续使用 B 系列页眉，标题下依次排列：

1. 全宽搜索纸页：家庭成员姓名输入框与“查找相关档案”主按钮同一行；窄宽度时按钮换到下一行并保持全宽。
2. 错误提示：紧邻搜索纸页，不占用结果表格内部空间。
3. 全宽结果纸页：标题区显示“查询结果”、匹配总数和“同名匹配不合并”说明。
4. 结果表格与固定分页：有结果时始终显示每页 20 条；无结果或尚未查询时在相同纸页位置显示对应空状态。

### 3.2 表格字段与操作

表格沿用原版信息顺序：

- 匹配成员：成员姓名为主文本，关系为次级标签；
- 档案姓名：空姓名显示安全占位；
- 单位 / 部门：同一单元格分两行呈现；
- 职务；
- 职称 / 技能；
- 档案操作：保留“查看档案”，进入现有独立详情路由。

每一条家庭成员匹配关系都独立显示，不按档案或姓名去重。页面不再维护“当前选中匹配项”，也不在查询页加载完整档案详情。

## 4. 批量导入档案

### 4.1 页面结构

页面继续使用 B 系列页眉，内容按业务流程纵向排列：

1. 文件选择纸页：左侧说明支持格式、数量与单文件上限，右侧保留“选择文件”和“上传并检查”操作。
2. 待处理文件区：文件存在时在选择纸页下方以紧凑文件条目展示，并保留本地每页 20 条分页；没有文件时不制造额外空白大栏。
3. 文件夹配置或导入错误提示：位于选择纸页与当前批次之间，保持现有错误优先级。
4. 当前批次纸页：始终保留稳定位置；有结果时显示全宽表格，没有批次时显示引导空状态。
5. 永久导入历史纸页：紧随当前批次，保留刷新操作、服务端 20 条分页和跨重启说明。

移除当前 B 版的 286px 待处理队列栏、238px 批次目录和章节导航；这些页面内容本身已经按处理顺序纵向排列，不再需要重复导航。

### 4.2 当前批次与历史表格

当前批次继续显示工作簿、来源、状态、处理说明、本地文件状态和操作。待决定项保留“处理”入口，自动归档失败保留“重试归档”。

永久历史继续显示处理时间、批次、工作簿、操作人、状态和处理说明。两张表格使用 B 系列表头、行高、状态标签和分页外观；宽度不足时只在纸页内部滚动，页面主体不产生横向滚动。

### 4.3 重复决定弹窗

重复档案弹窗保留现有 B 系列外观和全部行为：

- 默认选择 `SKIP`；
- `OVERWRITE` 必须显式确认；
- 只显示安全的重复摘要；
- 关闭、取消、失败或会话过期绝不隐含覆盖；
- 过期决定仍按稳定错误码引导重新预检。

## 5. 组件与状态边界

- `FamilySearchPage.vue` 只重组模板和页面局部状态；查询继续由 family-search store/API 负责。
- `ImportPage.vue` 只重组选择区、队列、当前结果和历史面板；上传、分片、决定及归档继续由 archive-import store 负责。
- `ImportHistoryPanel.vue` 保留服务端分页和刷新逻辑，只调整标题和纸页容器以适配新的纵向父布局。
- `FixedListPagination.vue`、分页容量常量和所有 schema 不变。
- 删除不再使用的匹配选择状态、批次章节常量和 `DossierOutline` 页面引用；不修改共享卷宗详情组件。

## 6. 响应式与可访问性

- 1440px：两个页面使用工作区全部可用宽度，卡片依次纵向展开。
- 1080px：搜索和选择操作可换行；表格容器可横向滚动；固定操作列仍可访问。
- 输入框保留明确标签和提交表单语义，按钮继续支持键盘操作。
- 加载和错误状态继续使用 `role="status"` 或 Element Plus 提示组件；空状态文字不依赖颜色表达。
- 不改变当前应用 1080px 最小窗口、60px 顶栏和 252px 侧栏。

## 7. 验证范围

### 7.1 单元与组件测试

- 家庭查询初始态、输入、查询、错误、多条同名结果、字段列、分页和查看档案跳转；
- 确认查询页不再创建匹配摘要选择状态，也不提前读取完整档案；
- 导入选择、队列分页、上传状态、当前批次、待决定、归档重试和永久历史；
- 确认两页不再渲染旧的左右/三栏容器与 `DossierOutline`。

### 7.2 Electron 视觉验收

- 更新 B 系列布局 E2E，在 1440×960 截取家庭查询和批量导入页面；
- 增加或更新 1080×800 断言，验证页面为单列纵向、操作可见且页面主体无横向溢出；
- 保留登录、人员卷宗、独立详情、删除、分页、真实 IPC 扫描归档和 ZIP 保存场景。

## 8. 非目标

- 不改变人员档案三栏卷宗检阅桌、独立详情页、登录页或文件夹设置页；
- 不恢复 Avue；结果表格继续使用 Element Plus；
- 不新增查询字段、导入状态、批量操作或后端接口；
- 不在本次改版中处理 macOS 开发模式 Dock 显示 Electron 的问题；
- 不修改根目录启动脚本，也不把 B 副本晋升为当前打包源。
