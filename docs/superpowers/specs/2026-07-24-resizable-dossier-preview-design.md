# 可拖拽卷宗预览与详情导航贴顶设计

**日期：** 2026-07-24

**范围：** 人员档案目录的卷宗预览，以及完整档案页的详情导航

**状态：** 已确认

## 目标

人员档案目录初次打开时不占用卷宗预览空间，名册使用全部可用宽度。用户点击名册行或“预览”后，卷宗从右侧滑入，名册同步平滑收窄；用户可以拖动两栏之间的分隔线调整卷宗宽度，并可从卷宗右上角关闭。完整档案页的详情导航在吸顶后必须紧贴工作区顶部，不能留下工作区内边距形成的空带。

## 交互设计

### 卷宗预览

- 初始状态不渲染卷宗预览，名册占满工作台。
- 点击名册行或“预览”按钮后立即打开右栏并显示加载状态，不等待详情请求完成才开始动画。
- 右栏在 `220ms` 内从右向左滑入，名册的网格列宽使用同一时长和缓动曲线平滑收窄；关闭时执行相反方向的动画。
- 预览默认宽度为 `320px`，可通过左边缘分隔线在 `280px` 至 `520px` 之间调整。
- 向左拖动分隔线扩大预览，向右拖动缩小预览。分隔线使用 Pointer Events 和指针捕获，避免拖出边界后丢失拖动状态。
- 分隔线具备 `separator` 语义、当前宽度和值域，并支持左右方向键每次按 `16px` 调整，保证键盘可用性。
- 当前页面生命周期内保留用户调整后的宽度；刷新、重启或重新进入页面时恢复默认宽度，不新增持久化设置。
- 右上角始终显示“关闭卷宗预览”按钮，包括加载、失败和就绪状态。
- 关闭时卷宗向右滑出，名册恢复全宽；关闭操作调用现有 `preview.clear()`，同时使未完成请求失效并释放临时照片 Object URL。
- 已打开预览时切换人员只更新右栏内容，不重复执行整栏进出动画。
- 筛选、重置和翻页继续清除当前预览，并使用相同的关闭动画。
- 继续遵守现有响应式规则：视口宽度不大于 `1280px` 时，预览移到名册下方，拖拽分隔线隐藏，避免名册操作列过窄。
- `prefers-reduced-motion: reduce` 下取消位移动画和列宽动画，状态变化仍立即生效。

### 详情导航

- 保持导航与档案标题在普通文档流中无缝相连。
- 导航吸顶时以工作区纵向内边距的负值作为 sticky 偏移：常规宽度抵消 `24px`，窄屏抵消 `20px`。
- 工作区内边距通过共享 CSS 自定义属性暴露，详情页只消费该值，不改变其他页面的布局。
- 分区的 `scroll-margin-top` 继续为吸顶导航预留空间，点击“基本与任职”“学历教育”“经历奖惩”“家庭与申报”后，分区标题不会被导航遮挡。

## 组件与状态边界

`PersonListPage.vue` 根据 `preview.state.kind !== "idle"` 决定分栏是否打开，并在本次页面生命周期内保留最后一次调整的宽度快照。现有 `usePersonPreview()` 继续负责详情请求、照片请求、过期响应隔离及资源释放，不新增第二套选中状态；行高亮继续由同一预览状态驱动。

`PersonPreviewDock.vue` 从页面快照初始化当前宽度，隔离 Pointer Events 拖拽、指针捕获和键盘调整，并把宽度变化、关闭、重试、查看与导出事件转发给页面。`PersonArchivePreview.vue` 只负责卷宗内容和统一关闭入口。

分栏使用 CSS Grid 的 `minmax(0, 1fr) auto` 两列：关闭时 Dock 不渲染且无列间距；打开时 Dock 通过 CSS 自定义属性提供宽度。Vue Transition 同时控制 Dock 的宽度、水平位移和透明度，工作台同步过渡列间距，使名册随 Dock 的 `0` 到目标宽度变化平滑收窄与恢复。

`ArchiveDetailPage.vue` 不增加滚动监听。贴顶修复只调整共享工作区内边距变量和 `.dossier-index` 的 sticky 偏移，避免引入易失配的 JavaScript 布局测量。

## 状态与失败处理

- 详情加载失败时右栏保持打开，用户仍可重试或关闭。
- 照片加载失败时沿用现有独立重试，不影响分栏状态。
- 加载中关闭会递增现有请求令牌；迟到响应不得重新打开预览或创建照片 URL。
- 拖拽值始终钳制在允许范围内；无效、重复或在窄屏下的拖拽事件不改变布局。
- 关闭不改变批量勾选，预览选中与批量导出选择继续相互独立。

## 测试与验收

### 单元测试

- 初始加载完成后不存在卷宗预览 DOM，详情和照片接口未调用。
- 点击行或“预览”后出现加载/就绪右栏，行高亮与请求行为保持正确。
- 点击关闭后预览 DOM 消失、行高亮清除，并调用现有资源清理路径。
- 拖拽分隔线能够增减宽度，并在 `280px`/`520px` 边界钳制。
- 分隔线方向键调整宽度，ARIA 当前值同步更新。
- 失败状态仍提供重试和关闭操作。
- 样式契约覆盖两列网格、`220ms` 进出动画、窄屏隐藏分隔线，以及详情导航抵消工作区内边距。

### Electron 端到端测试

- 登录进入人员档案时预览默认不可见，名册工作台占满宽度。
- 点击“预览”后右栏可见且名册宽度减小；右栏仍只显示服务端脱敏字段。
- 拖动分隔线后右栏宽度变化；点击右上角关闭后右栏不可见且名册恢复宽度。
- 完整档案页滚动后，详情导航的顶部与工作区滚动视口顶部对齐，不再保留内边距空带。
- 继续验证点击导航不会更改路由，敏感字段按需读取与照片资源行为不回归。

### 验证命令

运行 `pnpm lint`、`pnpm typecheck`、`pnpm test` 和 `pnpm build`。Electron E2E 必须遵守项目规则，在普通 macOS 桌面会话或 Windows CI 中运行；Codex Seatbelt 环境只验证其预启动失败策略，不强行启动 Electron。
