# B 版隐藏未配置文件夹提示设计

## 背景

`personnel-archive-desktop-b` 的批量导入页同时承载手动文件选择和自动文件夹扫描。管理员或档案编辑员登录后，应用会启动自动扫描；当两个自动扫描目录尚未配置时，扫描状态返回 `UNCONFIGURED`，页面因此显示“请先设置待上传文件夹和归档文件夹”的橙色警告。该提示容易被理解为手动导入的前置条件，但手动导入实际上不依赖这两个目录。

## 决策

批量导入页不再渲染 `UNCONFIGURED` 状态的自动扫描提示。页面仍显示其他自动扫描消息：

- `READY` 信息继续表达自动扫描已就绪或发现了工作簿；
- 目录丢失、读取失败等真实异常继续以警告显示；
- 手动导入自己的选择、上传和处理消息保持不变。

## 范围

本次只调整 `ImportPage.vue` 的扫描消息可见条件，并增加组件回归测试。以下行为不变：

- 自动扫描定时器、IPC、文件夹设置持久化与成功后归档；
- 手动选择、上传预检、重复决策、当前结果和历史记录；
- 文件夹设置路由及其当前隐藏的业务目录入口；
- 后端 API、数据库和权限模型。

## 验收与测试

组件测试应证明：

1. 扫描状态为 `UNCONFIGURED` 且带有提示文本时，批量导入页不显示扫描警告；
2. 扫描状态为真实失败状态时，页面仍显示对应警告；
3. 现有手动/自动导入测试、类型检查和构建保持通过。

该设计不删除功能，也不把错误静默化；它只消除一个与手动操作无关、容易造成误解的未配置提示。
