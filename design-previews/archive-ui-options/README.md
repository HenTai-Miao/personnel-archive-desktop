# 人员档案助手五版设计比较稿

这组文件是独立设计预览，不会被 Electron 客户端构建或加载。五个方案共享 `shared/preview-content.js` 中的合成测试数据和业务文案，确保比较时只有布局与视觉发生变化。

| 文件 | 方向 | 主要差异 |
|---|---|---|
| `option-1.html` | 蓝灰档案台账 | 延续当前侧栏和台账方向，风险最低 |
| `option-2.html` | 横向业务栏 | 主导航移到顶部，目录获得更多横向空间 |
| `option-3.html` | 纸质卷宗柜 | 冷灰纸张、卷宗页签和印章色，行业识别最强 |
| `option-4.html` | Windows 管理台 | 传统树形工具区和高密度数据网格，效率优先 |
| `option-5.html` | 双栏检索工作台 | 筛选固定在目录左侧，适合高频查询 |

从本目录启动静态服务器后打开 `index.html`，可在顶部切换五版并将当前方案单独打开。
