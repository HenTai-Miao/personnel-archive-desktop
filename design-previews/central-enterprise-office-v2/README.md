# 人员档案助手 · 国央企办公风格五版原型

本目录只用于视觉和信息架构比较，不参与 Electron 客户端构建，也不连接真实接口。现有 `src/`、测试、配置和业务逻辑均未修改。

五版共用同一组虚构脱敏数据，并提供“人员档案、家庭成员查询、批量导入、档案详情”四个代表页面。比较时可以排除业务内容差异，重点判断全局骨架、信息层级、操作密度和视觉气质。

| 文件 | 方向 | 结构重点 | 记忆点 |
|---|---|---|---|
| `option-1.html` | 总部稳健门户 | 深蓝顶栏 + 白色左导航 + 单一主工作区 | 红色档案脊线 |
| `option-2.html` | 双层综合办公 | 顶部一级模块 + 左侧二级目录 | 门户式双层导航 |
| `option-3.html` | 档案阅办工作台 | 图标窄轨 + 固定检索栏 + 目录/预览并排 | 卷宗侧签与快速预览 |
| `option-4.html` | 红蓝公文台账 | 横向模块栏 + 居中公文式工作区 | 文号签头与状态方印 |
| `option-5.html` | 高密度业务台 | 深色主导航 + 顶部命令栏 + 右侧当日任务栏 | 三栏协同工作台 |

打开 `index.html` 可在同一窗口切换比较，也可以单独打开任意 `option-*.html`。

## 设计约束

- 保留人员档案系统既有中文业务词汇，不伪造任何真实企业名称或标识。
- 控件保持 Windows 办公软件的明确边界，但避免当前版本的树形连线、过重边框和 9–11px 小字号。
- 红色仅用于品牌识别、当前状态或高风险动作；正常业务操作仍以蓝色、墨色和中性色为主。
- 原型以 1440×900 桌面窗口为主要评审尺寸，兼顾 1180px 以上窗口缩放。
